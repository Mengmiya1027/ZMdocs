# 这个网站有什么特点

说起来，这个网站也没什么了不起的特点。<br>
就是个随手写东西的小地方。但既然侧边栏写了"特点"两个字，总得凑点东西出来。

## 随便写

不用排期，不用计划，不用"本周主题"。<br>
梦到什么写什么，写到哪算哪。有时候是一篇技术笔记，有时候是半夜睡不着敲下的胡思乱想。

## 看着顺眼

配色、排版、还有那些小动画，都是两个人吵了无数次架才定下来的。<br>
你可能觉得也就那样，但这是我们能互相妥协、都勉强接受的版本了。

## 进得来，出得去

没有会员，没有弹窗，没有"不收藏就再也找不到"的恐吓。<br>
想看就看，不想看关掉就行。它不会追着你推送，也不会在你走了之后假装舍不得。

## 有点小讲究

比如你刚刚点进这个页面时，正文从右边轻轻滑进来、淡入——<br>
这种细节没人会专门夸，但少了又会觉得"哪里不对"。我们就是在这上面较劲的人。

---

特点大概就这些。<br>
要是你一路看到了这里，那说明我们写得还算能看。
