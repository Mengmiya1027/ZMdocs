# 小天才Z8root教程

## 免责声明
本教程仅针对特定机型及特定系统版本，且存在不可逆的变砖风险（黑屏/9008深刷/硬件损坏），建议在刷机前备份重要数据，并在刷机过程中保持冷静。如果在刷机过程中遇到问题，建议寻求专业人士的帮助。<br>
若您未完全理解fastboot、Magisk原理，请立即关闭本页面。因操作失误或文件不匹配导致的任何软硬件故障，本人概不负责，请自行通过售后或第三方维修解决。<br>
注：演示的工具箱使用的是XTC AllToolBox `1.3.7Spro`版本，手表`Z8`,版本号是`3.3.0`<br>

## 准备工作
1. 一个一字螺丝刀或者是镊子等导体（用于短接）<br>
2. 一根4点数据线或者6点数据线（用于连接电脑，见下文[数据线选择](#数据线选择)）<br>
3. 一台电脑<br>
4. XTC AllToolBox >=`1.3.7Spro`工具箱<br>
5. 小天才Z8手表<br>

## 数据线选择
观察手表充电口中间的两个触点是否颜色深于外侧两个点，或者使用小天才原装取卡器取下卡槽，观察卡槽触点数量。

如果您的手表充电口中间的两个触点颜色深于外侧两个点，或是卡槽触点数量>4个，请使用6点数据线

反之，您则可以使用相对便宜的四点侧边数据线。

## 刷机前确认
手表电量保持在 **50%**以上<br>
确认手表型号为 `Z8`，系统版本号为 `3.3.0`（与本教程验证版本一致）<br>
确认数据线连接电脑后，电脑能识别到手表（在设备管理器里能看到端口）<br>
如果以上任何一条不满足，请先处理完毕再继续

## 刷机步骤
安装好驱动后，打开XTC AllToolBox >=`1.3.7Spro`工具箱。如果提示更新就更新，进入主菜单后输入`1`选择`一键root`。此时工具箱进入等待手表连接的状态.<br>
将开机状态下手表插上4点数据线并连接电脑之后打开sim后盖，将一字起或镊子短接手表的两个相邻的金属点并按住手表电源键保持不动，直到工具箱提示连接成功。<br>
<br>
连接成功后，由于XTC AllToolBox 1.3.7Spro是全自动轮椅，你可以放心的把它晾着并刷视频<br>
当工具箱显示出这样的时候：
:::code-group
```bash
是否进行预装优化[包括模块和应用，期间需多次选择]？
1.是
2.否
```
:::
那么恭喜你已经root完毕了 <br>

## 预装优化
选择`1`开始进行预装优化，该过程可能很长。期间需多次选择是否执行。这里的选择可以看个人喜好
<br>
**重要提示：**
若您的手表在root预装优化时不处于正常使用模式（即处于**上课禁用、长续航模式、高温禁用、睡眠模式**等），那么**请勿**安装禁用模式切换的桌面！

## 额外指南

请勿卸载Magisk、Lsposed等应用及其内部原有模块，除非您急需一块砖。<br>
浏览器、应用商店、安装器等应用可以**但不建议**卸载。重新安装可能需要连接电脑。<br>
