# 小天才Z10root教程

## 免责声明
本教程仅针对特定机型及特定系统版本，且存在不可逆的变砖风险（黑屏/9008深刷/硬件损坏），建议在刷机前备份重要数据，并在刷机过程中保持冷静。如果在刷机过程中遇到问题，建议寻求专业人士的帮助。<br>
若您未完全理解fastboot、Magisk原理，请立即关闭本页面。因操作失误或文件不匹配导致的任何软硬件故障，本人概不负责，请自行通过售后或第三方维修解决。<br>
注：演示的工具箱使用的是XTC AllToolBox `1.4.0`版本，手表`Z10`,版本号`2.8.1`或者`3.0.2`<br>

## 准备工作
1. 一根6点数据线（用于连接电脑）<br>
2. 一台电脑<br>
3. XTC AllToolBox >=`1.4.0`工具箱<br>
4. 小天才Z10手表<br>

## 重要提示： 
### 请勿使用版本号 < 1.4.0的ATB工具箱。反之可能带来部分功能缺失的问题

## 刷机前确认
手表电量务必保持在 **50%**以上<br>
确认手表型号为 `Z10`，系统版本号为 **2.8.1** 或者 **3.0.2** <br>
确认数据线连接电脑后，电脑能识别到手表（在设备管理器里能看到端口）<br>
如果以上任何一条不满足，请先处理完毕再继续


## 刷机步骤
安装好驱动后，打开XTC AllToolBox >=`1.4.0`工具箱。如果提示更新，更新完毕后进行下一步。<br>
进入主菜单后输入`1`选择`一键root`。此时工具箱进入等待手表连接的状态.<br>
开机状态下，打开手表sim后盖，将手表插上6点数据线并连接电脑，按住6点线上的按钮并按住手表电源键保持不动，直到工具箱提示连接成功。<br>

连接成功后，由于XTC AllToolBox 1.4.0是全自动轮椅，你可以放心的把它晾着并刷视频。<br>
当工具箱显示出这样的时候：

:::code-group
```bash
- 跨越山海 终见曙光 -
您的手表已ROOT完毕，耗时：.......
```
:::

那么恭喜你已经root完毕了 <br>

## 额外指南

请勿卸载Magisk、Lsposed等应用及其内部原有模块，除非您急需一块砖。<br>
浏览器、应用商店、安装器等应用可以**但不建议**卸载。重新安装可能需要连接电脑。<br>
如果您发现`弦-安装器`无法安装应用至您的手表，请使用QQ群文件内专为`Z10/Android11`制作的`弦-安装器`或者使用`mt管理器`或`Poke安装器`安装
