# QMMI（高通全功能测试模式）

是高通平台设备内置的硬件自检工程模式，全称为 Qualcomm Manufacturing Mode Interface。它作为系统级 APK 应用运行，提供屏幕、触摸、指纹、摄像头、传感器等数十项硬件功能的诊断与测试入口，主要用于工厂产线质检和售后维修场景。<br>
<br>
在小天才手表上，QMMI 是绕过系统限制、进入硬件测试界面的后门通道。由于小天才系统通常屏蔽了拨号暗码，玩家需要通过 ADB 命令强制拉起 QMMI 主界面。进入后，通过在 QMMI 内部执行特定操作（如选择"重启到 QMMI 模式"再重启回来），可以触发系统 ADB 开关被重新激活，从而在手表的开发者选项中被隐藏或置灰的"USB 调试"选项得以再次开启。这是目前安装第三方应用最主要的突破口。
